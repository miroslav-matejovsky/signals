# Principles

Principles capture the truths that define a system and the way it is built. They outlive
technologies, frameworks, and implementation details.

Principles always apply. Consider them before every decision. One principle per file.

| Principle | Description |
|-----------|-------------|
| [Experimentation](experimentation.md) | Maximize learning by minimizing commitments |
| [Configuration Is Documentation](configuration.md) | Operationally significant behavior is explicitly configurable, documented, visible, and owned. |
| [Evidence Before Assumption](evidence.md) | Observe and measure before concluding, so unverified hypotheses never become engineering facts. |
